# E-commerce Data

## Project Overview
This project is a Power BI-based analytics implementation built on sales and product data for an e-commerce scenario.

## Data
The local project contains fact and dimension tables covering sales, customers, campaigns, channels, payment, product, and region data.

## Solution
The semantic model is designed to support performance and trend analysis across product, customer, and channel dimensions using Power BI measures and report pages.

## Technologies
- Power BI
- CSV source files
- semantic model design
- DAX reporting
